# Data safety

1. Keep at least two backup destinations, preferably one cloud-synchronised folder and one external drive.
2. Use the integrity checker before major imports or restores.
3. Do not open the same portable data folder simultaneously on multiple computers.
4. Keep encrypted-backup passwords in a password manager. Lost passwords cannot be recovered.
5. Test restoring a backup before relying on it as the only archive.
6. Retain the original photographs and scanned documents outside the application when they are irreplaceable.
