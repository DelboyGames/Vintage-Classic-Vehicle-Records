CLEAN GITHUB REPOSITORY UPLOAD — VERSION 7.1

1. Extract this ZIP.
2. Open the extracted project folder.
3. Upload EVERYTHING INSIDE the folder to the root of your GitHub repository.
4. package.json must appear at the repository root.
5. Keep the hidden .github folder; it contains the build workflow.
6. Commit the files to the main branch.
7. Open Actions > Build Windows Editions with USB Creator.
8. Choose installer, portable, or both.

The official icon is assets/app.ico. Do not rename or move it unless you also update the Electron Builder configuration.
