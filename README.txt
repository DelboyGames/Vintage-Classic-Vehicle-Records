VINTAGE & CLASSIC VEHICLE MAINTENANCE & RESTORATION RECORDS
COLLECTOR EDITION — VERSION 7.2

Version 7.2 adds launch-time update notifications for the installed edition and release metadata required for automatic updates.

IMPORTANT RELEASE MODEL
Normal build workflows do NOT publish releases automatically and do not require GH_TOKEN. Use the separate “Publish Version 7.2 GitHub Release” workflow when you intentionally want to publish a release.

BUG REPORT PRIVACY
Bug reports open a GitHub issue draft for review. Vehicle records, VINs, registrations, photographs, documents, addresses, backups and the SQLite database are not automatically uploaded.

UPDATES
The application checks the latest GitHub Release. The installed edition uses Electron's update mechanism.
